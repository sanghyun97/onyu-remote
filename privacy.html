개인정보 처리방침

온유 리모트 · 시행일 2026년 11월 11일 (1.1)

온유 리모트는 개인정보를 수집하지 않습니다. 개발자나 제3자의 서버로 어떤 정보도 보내지 않으며, 광고·분석·추적 도구를 쓰지 않습니다.

앱이 다루는 정보

  • 화면·입력·파일: 사용자가 연결한 자신의 기기끼리 직접 주고받습니다. 전송 내용은 연결마다 새로 만든 키로 암호화되며, 어디에도 저장하지 않습니다.
  • 페어링 정보: 처음 연결할 때 만든 페어링 열쇠와 기기 이름은 각 기기 안에만 저장됩니다(아이폰·아이패드는 키체인). 앱을 지우면 함께 지워집니다.
  • 받은 파일: 맥 ↔ 맥 파일 전송으로 받은 파일은 받는 맥의 다운로드/온유 리모트 폴더에만 저장됩니다.
  • 로컬 네트워크: 같은 Wi-Fi에 있는 맥을 찾기 위해서만 사용합니다.
  • 맥 알림 받기(선택): 사용자가 켜면, 맥이 보내는 알림(제목·내용·맥 이름)을 사용자 본인 iCloud 계정의 개인 저장소(Apple CloudKit)에 잠시 저장해 같은 계정의 아이폰·아이패드로 전달합니다. 개발자는 이 저장소에 접근할 수 없으며, 기록은 이틀 뒤 맥이 지웁니다.
  • 다른 앱 알림 전달(선택, 맥): 사용자가 직접 고른 앱의 알림만 맥의 알림 센터 기록에서 읽어 위 방식으로 전달합니다. 기본으로 꺼져 있고, 켜려면 사용자가 '전체 디스크 접근' 권한을 줘야 합니다. 고르지 않은 앱의 알림 내용은 읽지 않습니다.
  • 클립보드 공유(선택, 맥 ↔ 맥): 연결된 두 맥 사이에서 복사한 글자만 암호화해 주고받으며 저장하지 않습니다. 암호 관리자가 숨김으로 표시한 내용은 보내지 않습니다.
  • 진단 기록(맥): 연결 시작·끝, 오류 같은 동작 기록만 맥 안(~/Library/Application Support/MacRemote)에 남깁니다. 화면·입력·알림 내용은 남기지 않습니다.

외부 서비스

맥 알림 받기는 Apple의 iCloud(CloudKit)와 푸시 알림을 사용하며, Apple의 개인정보 처리방침을 따릅니다.

밖에서 연결할 때 사용자가 직접 설치한 Tailscale을 쓸 수 있습니다. Tailscale은 별도 서비스이며 그 회사의 개인정보 처리방침을 따릅니다. 온유 리모트는 Tailscale에 어떤 정보도 따로 보내지 않습니다.

Privacy Policy (English)

Onyu Remote does not collect any personal data. Screen, input and files are sent only between the user's own devices, end-to-end encrypted per connection, and are not stored. Pairing keys stay on each device. No analytics, ads or tracking. Optional Mac-to-iPhone alerts are stored briefly in the user's own private iCloud database (Apple CloudKit), which the developer cannot access, and are deleted after two days. Forwarding other apps' notifications is off by default and reads only the apps the user selects. Clipboard sharing between Macs is encrypted and not stored.
