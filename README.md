# 온유 리모트 홈페이지

https://sanghyun97.github.io/onyu-remote/ — 소개, 맥 앱 내려받기, 설치 안내, 지원, 개인정보 처리방침, 변경 기록.

- 페이지는 `_build.py`가 만든다: 내용·버전 기본값을 고치고 `python3 _build.py`.
- 디자인 규칙은 `DESIGN.md`(애플 스타일 분석 문서), 값은 `style.css`.
- 맥 설치 파일은 Releases에 `OnyuRemote-<버전>.dmg`와 고정 이름 `OnyuRemote.dmg` 두 개로 올린다. 페이지는 최신 릴리스 정보를 읽어 버전·크기·SHA-256을 채운다(`site.js`).
- `support.html`, `privacy.html` 주소는 App Store에 등록돼 있으니 바꾸지 말 것.
